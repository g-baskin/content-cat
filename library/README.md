# Library

Documentation root for this repository. Schema version: **v2**.

See [Documentation Framework](knowledge/private/standards/documentation-framework.md) for repository-specific schema and ownership rules.

## Top-level layout

| Folder                 | What goes here                                                            |
| ---------------------- | ------------------------------------------------------------------------- |
| `knowledge/public/`    | End-user / customer-facing docs: overviews, guides, FAQs                  |
| `knowledge/private/`   | Internal engineering and business docs: ADRs, standards, domain knowledge |
| `knowledge-base/wiki/` | Code-derived entity pages owned by Wiki Guardian                          |
| `requirements/`        | Product and feature work: PRDs in backlog/in-work/completed               |
| `issues/`              | Reactive bug and incident work: IRDs in backlog/in-work/completed         |
| `notes/`               | Human-only scratch space                                                  |

## What does NOT belong here

- Brand assets and binary media → the appropriate repository asset folder
- Aggregated documentation mirrors → derived outputs, never edit directly
- Wiki global-state files → generated by the wiki driver, never edit manually
